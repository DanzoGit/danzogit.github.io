# Проверки читалки Markdown

```sh
node --test tests/md-reader.test.cjs
```

Тесты используют только встроенные модули Node.js и настоящие функции из
`assets/md-reader/reader.js`. Устанавливать npm-зависимости не нужно.

Проверяются:

- локальное отображение времени в `Europe/Moscow` и `Asia/Irkutsk`;
- сохранение календарного дня у значения `date: YYYY-MM-DD` без времени;
- приоритет `published_at`/`updated_at` над HTTP `Last-Modified` для Steam-новостей;
- сохранение исходного `datetime` и обработка некорректной даты;
- скрытие/возврат панели разделов и сохранение выбора нескольких файлов.

Дополнительно в браузере следует проверить новость без разделов, документ с h2/h3,
переключение между ними, мобильную панель, поиск, светлую/темную темы,
выбор и перетаскивание Markdown вместе с изображениями.

Время отображается в часовом поясе браузера. Исходные ISO-даты в Markdown и
атрибуте `<time datetime>` не меняются. Если у Steam-новости нет собственной даты,
время деплоя сайта не используется вместо нее.
